КАСА: застосунок для телефона, планшета й комп'ютера
=====================================================

У цій папці немає жодних ваших даних: тільки код. Дані лежать на ваших пристроях
і (якщо підключите хмару) у вашому ПРИВАТНОМУ репозиторії GitHub.

1) РОЗМІСТІТЬ ПАПКУ В ІНТЕРНЕТІ (один раз)
   Варіант А, GitHub Pages:
   - github.com -> New repository -> назва kasa-app -> Public -> Create.
   - Add file -> Upload files -> перетягніть ВСІ файли з цієї папки -> Commit.
   - Settings -> Pages -> Source: Deploy from a branch -> main / (root) -> Save.
   - Через хвилину адреса буде такою: https://ВАШ-ЛОГІН.github.io/kasa-app/
   Варіант Б, Netlify Drop: відкрийте app.netlify.com/drop і перетягніть папку.

2) ВСТАНОВІТЬ НА ТЕЛЕФОН / ПЛАНШЕТ
   - Android (Chrome): відкрийте адресу -> меню з трьома крапками -> «Установити застосунок».
   - iPhone / iPad (Safari): відкрийте адресу -> «Поділитися» -> «На початковий екран».

3) УВІМКНІТЬ СИНХРОНІЗАЦІЮ (один раз на кожному пристрої)
   У застосунку: Ще -> «Підключити хмару» і виконайте кроки з підказки.
   На другому й наступних пристроях достатньо вставити «код підключення»
   (Ще -> Код підключення на першому пристрої).

Можна також просто відкрити index.html на комп'ютері, без розміщення в інтернеті.
